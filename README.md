# React Mini Shop

Учебный интернет-магазин, созданный на React + Vite.

Проект сделан для практики React, маршрутизации, работы с состоянием, массивами, localStorage и базовой логики интернет-магазина.

## 🌐 Демо

[Открыть Mini Shop](https://react-mini-shop-eosin.vercel.app)

## 🚀 Возможности

- Регистрация пользователя
- Сохранение состояния регистрации
- Выход из аккаунта
- Навигация между страницами через React Router
- Главная страница
- Страница товаров
- Страница корзины
- Поиск товаров
- Сортировка товаров по цене
- Добавление товаров в корзину
- Увеличение количества товара
- Уменьшение количества товара
- Удаление товара из корзины
- Очистка всей корзины
- Подсчёт общей стоимости
- Сохранение корзины через localStorage
- Светлая и тёмная тема
- Адаптивная версия для мобильных устройств

## 🛣 Маршруты

- `/` — главная страница
- `/products` — товары
- `/cart` — корзина
